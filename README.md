# Prime Beta Games — Website Starter

A responsive, animated static website for the Prime Beta Games mobile game studio.

## Included
- Home page with animated hero, sample game portfolio, studio positioning and contact CTA
- About page
- Contact & Support page with a mailto-based form
- Privacy Policy template
- Terms of Service template
- Responsive navigation, scroll reveals, reduced-motion support, favicon and SEO basics

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For a closer-to-hosted preview, use VS Code's Live Server extension.

No build tools or package installation are required.

## Before publishing — important checklist
1. **Domain:** choose a domain and check availability at checkout. Suggested first choice: `primebetagames.com`; alternatives: `primebetagames.studio`, `primebetagames.games`, or `primebetagames.com.pk`. These are suggestions only; availability has not been verified.
2. **Contact email:** create an address on your final domain (for example `support@yourdomain.com` and `business@yourdomain.com`) and replace `CONTACT_EMAIL` in `script.js`.
3. **Store links:** edit the sample game cards in `index.html` and replace each `href="#"` with the actual Google Play, Apple App Store, Amazon Appstore, Samsung Galaxy Store or other live listing URL. Replace the stylized sample art with your real game icons/screenshots if desired.
4. **Legal pages:** update `privacy.html` and `terms.html` based on the actual data collection, ads/analytics SDKs, age groups, purchases, deletion methods and countries where your games are available. The legal pages are starter templates, not legal advice. Do not publish them unchanged without checking accuracy.
5. **Contact form:** the current form opens the visitor's email application using `mailto:`. It does not send or store submissions on a server. For a true website contact form, connect a form backend/provider and add spam protection.
6. **Hosting:** upload the contents of this folder (not the outer folder) to your web host's public web root, often named `public_html`. Enable HTTPS/SSL.
7. **Test:** check all pages on mobile and desktop, verify email links and store URLs, and confirm the privacy policy URL is accessible without login.

## Domain recommendation
For a global mobile games brand, prefer a short `.com` if available. Register under the company owner's details, enable auto-renewal, use a strong unique account password and two-factor authentication, and check renewal costs before paying. Availability and pricing can change.
